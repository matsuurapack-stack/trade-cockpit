# 利用開始チェック表（管理者専用）

**このファイルに、パスワードやURLの実値を書かないでください（Gitに保存されます）。**
実際のユーザー名・初期パスワードは、紙・パスワード管理アプリ・ローカルの別メモに控えてください。
ここには「済んだかどうか」のチェックだけを付けます。

## 共通（最初に1回）

- [ ] 旧`secrets.json`の`"users"`（平文）を削除した（または環境変数`APP_USERS`を削除した）
- [ ] `python manage_users.py list` で owner が表示される
- [ ] `python audit_watchlist_shared.py` で監視銘柄の棚卸しを確認した
- [ ] owner の手動監視銘柄を owner 個人へ移した（`migrate_watchlist_manual_to_owner.py --apply`）
- [ ] `python e2e_multiuser_privacy.py` が「全て合格」だった
- [ ] 渡すURLが **https**（Render等）または自宅Wi-Fi/Tailscale限定であることを確認した
- [ ] Neonのバックアップを取った
