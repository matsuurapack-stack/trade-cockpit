# トレード・コックピット かんたんマニュアル（利用者1さん用）

このマニュアルは、スマホやパソコンが得意でない方でも使えるように、やさしく書いています。
わからないところは、そのまま管理者に聞いてください。

---

## はじめに

このアプリには、2種類の情報があります。

1. **みんなで共通して見る相場情報**
   　今日の注目銘柄、ニュース、イベント（日銀やFOMCなどの予定）など。全員が同じものを見ます。
2. **自分だけが見る取引情報**
   　あなたの
   - **ポジション**（持っている株）
   - **トレード分析**（自分の売買の振り返り）
   - **今日の振り返り**

   は、**他の利用者には表示されません。** あなたの分も、他の人の分は見えません。

---

## iPhoneで使う

**① Safariを開く**
青いコンパスのマーク「Safari」を押します。

**② URLを入力**
管理者から送られたURLを押します。（またはSafariの上の細長い欄にURLを入力します）

**③ ログイン**
管理者から渡された次の2つを入力します。
- ユーザー名
- パスワード

**④ ログインボタン**
「ログイン」を押します。

### iPhoneのホーム画面に追加する（おすすめ）

1. Safariでアプリを開きます。
2. 画面の下にある「□に↑がついたマーク」を押します。
3. 「ホーム画面に追加」を押します。
4. 「追加」を押します。

次回からは、ホーム画面のアイコンを押すだけで開けます。

---

## パソコンで使う

1. ChromeまたはEdgeを開きます。
2. 管理者から届いたURLを開きます。
3. ユーザー名とパスワードを入れます。
4. 「ログイン」を押します。

---

## 使い終わったら（ログアウト）

画面の一番上に **「ログイン中：（あなたの名前）」** と **「ログアウト」** ボタンが出ています。
使い終わったら「ログアウト」を押してください。**家族や他の人と共用のスマホ・パソコンでは、必ずログアウトしてください。**

---

## 画面の見かた（上のボタンで切りかえます）

画面の上に、次のボタンが並んでいます。むずかしい言葉は使いません。

**みんなで同じものを見る画面**

- **監視銘柄**
  　気になる銘柄のリストです。システムが自動で見ている銘柄は全員共通、**あなたが自分で追加した銘柄は、あなただけ**に表示されます。
  　このほか「🎯 今日の注目 TOP5」（今日、大きく動く可能性がある銘柄）や、「🎯 今買い時TOP5」（チャートや出来高から、買う条件が整ってきた銘柄）も表示されます。
- **🌅 朝一**（朝一チェック）
  　朝のうちに、その日の相場の様子と注意点をまとめて見られます。
- **市場**
  　「概況」で日経平均・為替・アメリカ株など相場全体の様子、「日本株一覧」「米国株一覧」で銘柄の一覧を見られます。
- **イベント**
  　決算や日銀、FOMC（アメリカの金利を決める会議）などの予定を「カレンダー」で見られます。
- **ニュース**
  　株価に影響しそうなニュースを表示します。
- 「Radar」「HOT」などの表示は、急に株価や出来高が動き始めた銘柄を知らせるものです。

**あなただけが見る画面（他の人には見えません）**

- **ポジション**
  　自分が保有している銘柄を見る画面です。この内容は他の利用者には見えません。
- **今日の振り返り**
  　今日の自分の売買を振り返る画面です。この内容も本人だけが見ることができます。
- **記録**
  　自分の売買の記録、反省メモ、自分のルール、成績のまとめなどを見る画面です。他の人の取引は表示されません。
- **トレード分析**
  　銘柄ごとの分析画面です。自分の保有や売買に関わる部分は、あなたの分だけが使われます。

**そのほか**

- **📥 Smart Import**
  　コピーした文章などを取り込む画面です。取り込んだ内容は、種類によって「みんなの情報」または「自分だけの情報」に分かれて保存されます。

**画面の一番上の「リアルタイムデータを反映」ボタン**
　最新の株価などを取り直したいときに押します。

---

## 注意事項

- アプリが「買い」と表示しても、**必ず上がるわけではありません。**
- **急に値動きが変わる**ことがあります。
- **最終的に売り買いを決めるのは、あなた自身**です。
- **パスワードを他人に教えないでください。**

---

## 困ったとき

| こまったこと | やってみること |
|---|---|
| 画面が開かない | SafariまたはChromeを一度閉じて、もう一度開く |
| データが更新されない | 画面の「リアルタイムデータを反映」ボタンを押す |
| ログインできない | ユーザー名とパスワードをもう一度確認する（大文字・小文字も区別されます）。何回も間違えると10分ほど入れなくなります。少し待ってからやり直してください |
| 「ログイン」画面に戻ってしまう | しばらく使わないと自動でログアウトされます。もう一度ログインしてください |
| わからない | 管理者へ連絡 |
