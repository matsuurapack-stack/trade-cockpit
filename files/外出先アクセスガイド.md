# 外出先（自宅Wi-Fi以外）から使うためのガイド

自宅のPCを起動していなくても、スマホや外出先のPCからいつでもコックピットを開けるように
インターネット上（Render.com、無料プラン）にサーバーを置く方法です。

このガイドの手順のうち、**GitHubへのアップロード・Renderへの登録・パスワードや秘密鍵の入力は
ご本人にしかできません**（Claudeが代わりに行うと安全上まずいため）。Claudeは各手順の準備・
確認・トラブル対応をお手伝いします。

---

## 全体の流れ

1. GitHub（コード保管サービス）に非公開リポジトリを作る
2. コードをそこへアップロードする（Claudeが手伝えます）
3. Render.com（サーバー実行サービス）にGitHubを連携してデプロイする
4. Renderの管理画面で、パスワードとAPIキー・秘密鍵を設定する（ここは必ずご本人の作業）
5. 発行されたURLをスマホのブックマークに入れる

---

## 1. GitHubに非公開リポジトリを作る

1. https://github.com/new を開く（GitHubアカウントが無ければ先に無料登録）
2. Repository name: `trade-cockpit`（何でもよい）
3. **Private**（非公開）を必ず選ぶ ← 重要
4. 「Create repository」
5. 表示されたリポジトリのURL（`https://github.com/あなたの名前/trade-cockpit.git`）を
   Claudeに伝えてください。そこからのアップロードはClaudeが行えます。

---

## 2. Render.comにサインアップする

1. https://render.com を開き、GitHubアカウントでサインアップ
2. 「New +」→「Blueprint」
3. 手順1のリポジトリを選択（`render.yaml` を自動で読み込み、
   このプロジェクト用の設定を反映してデプロイが始まります）

---

## 3. パスワードを設定する（必須）

立花証券API連携後は気配値等の実データが載るため、**インターネット公開時は必ずパスワードを
かけてください**。

1. Renderのサービス画面 →「Environment」タブ
2. 「Add Environment Variable」
   - Key: `APP_PASSWORD`
   - Value: 好きなパスワード（家族と共有する合言葉。第三者に推測されにくいものを）
3. 保存すると自動で再デプロイされます
4. 以降、そのURLを開くとブラウザ標準のログイン画面が出ます
   （ユーザー名は何でもよく、パスワードだけ照合されます）

---

## 4. 立花証券APIの認証情報・APIキーを設定する（必須・ご本人の作業）

このPC（`files`フォルダ）にある以下の3ファイルの中身を、Renderの「Secret Files」機能で
そのままコピーします（Claudeはこの中身を扱えないため、ここだけはご自身での作業になります）。

1. Renderのサービス画面 →「Environment」タブ →「Secret Files」
2. 「Add Secret File」を3回、以下の組み合わせで追加：
   - Filename: `files/e_api_authid.txt` → Contents: `e_api_authid.txt` の中身をそのまま貼り付け
   - Filename: `files/e_api_private_key.pem` → Contents: `e_api_private_key.pem` の中身をそのまま貼り付け
   - Filename: `files/secrets.json` → Contents: `secrets.json` の中身をそのまま貼り付け
3. 保存すると自動で再デプロイされます

※ これらのファイルは中身が空白1つでもずれると認証に失敗します。エクスプローラーで
  メモ帳等で開き、全選択（Ctrl+A）→コピー（Ctrl+C）してそのまま貼り付けるのが確実です。

---

## 5. 完成後の使い方

- 発行されたURL（例：`https://trade-cockpit-xxxx.onrender.com`）をスマホのホーム画面や
  ブックマークに追加すれば、外出先でも自宅と同じように開けます。
- **無料プランは15分アクセスが無いと自動で休止し、次のアクセス時に起動し直す**ため、
  最初の1回だけ表示に数十秒かかることがあります。
- データ（登録銘柄など）は、このクラウド版・自宅PC版・スマホ版でそれぞれ別々に保存されます。
  同じ内容にしたい場合は「バックアップ↓／復元↑」でJSONを移してください。

---

## トラブルシューティング

- ログイン画面でパスワードを入れても入れない → `APP_PASSWORD` の値を確認（前後の空白等）
- 株価やニュースが「未接続」のような空表示になる → Secret Filesの中身がずれていないか確認
- デプロイが失敗する → Renderの「Logs」タブにエラーメッセージが出るので、それをClaudeに
  貼り付けてもらえれば原因を調べます
