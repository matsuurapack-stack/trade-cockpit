# トレード・コックピット（サーバー版・Windows）

「リアルタイムデータを反映」ボタンを押すたびに、株価・指数・為替・ニュースを
その場で取ってくる仕組みです。裏で Python の小さなサーバーが動きます。

---

## 仕組み

`start.bat` を起動 → Python のサーバーが立ち上がり、ブラウザが自動で開く →
画面の「リアルタイムデータを反映」ボタンを押すと、その瞬間にデータを取得して反映します。

以前の run.bat / fetch_data.py / バックアップJSONの配置は、もう使いません。

---

## フォルダの中身（5つとも同じフォルダに）

- trade-cockpit.html … コックピット本体
- server.py … データを取ってくるサーバー（触らなくてOK）
- start.bat … 毎回これをダブルクリックして起動する
- setup.bat … 最初の1回だけの準備
- README.md … この手順書

---

## 初回だけの準備

Python はもう入っている前提です（まだなら python.org から「Add python.exe to PATH」に
チェックを入れてインストール）。

setup.bat をダブルクリックして、必要な部品（yfinance・feedparser）を入れてください。
※ すでに実行済みでも、もう一度やって問題ありません。

---

## 毎回の使い方

1. start.bat をダブルクリックします。
2. 黒いウィンドウが開き、ブラウザが自動でコックピットを開きます。
   （開かない場合は http://localhost:8765/trade-cockpit.html を開く）
3. 使っている間、黒いウィンドウは閉じないでください（サーバーが止まります）。
4. 日次モニター右上の「リアルタイムデータを反映」ボタンを押すと、
   ドル円・日経平均・ダウ・ナスダック・SOX・米10年債 が
   今日値／前日値ともに入り、登録銘柄とマクロのニュースも入ります。
   何度押しても、そのたびに最新を取り直します。
5. 終わるときは、黒いウィンドウを閉じてください。

---

## スマホから使う

start.bat を動かしているPCと**同じWi-Fi**につないだスマホ・タブレットからも見られます。

1. PCで start.bat を起動すると、黒いウィンドウに
   `http://192.168.x.x:8765/trade-cockpit.html` のような行が表示されます（数字はPCごとに違います）。
2. 初回だけ、Windowsで「Windows セキュリティの重要な警告」（ファイアウォールの確認）が出ることがあります。
   「プライベートネットワーク」にチェックが入っていることを確認して「アクセスを許可する」を押してください。
   （この確認が出ないとスマホから繋がりません）
3. スマホのブラウザで、手順1のURLをそのまま開きます。

**注意点**
- PCの黒いウィンドウを閉じるとスマホからも使えなくなります（PCがサーバー役のため）。
- ユーザー名・パスワードでのログイン（Basic認証）が設定されている場合、同じWi-Fiにいても
  ログインなしでは中身は見られません。ただし公衆Wi-Fi（カフェ等）では念のため使わないでください。
- 登録銘柄やメモなどのデータは**端末（ブラウザ）ごとに別々に保存**されます。PCで登録した銘柄が
  スマホに自動で出てくるわけではありません。同じ内容にしたい場合は、PC側で「バックアップ↓」→
  スマホ側で「復元↑」からJSONを読み込んでください。

## 外出先（別Wi-Fi・4G/5G）から使う（Tailscale経由）

同じWi-Fiにいなくても、外出先のスマホからTrade Cockpitを見たい場合は、**Tailscale**という
無料の個人用VPN（プライベートネットワーク）アプリを使います。ルーターのポート開放や、
インターネットへの直接公開は一切行いません。PCとスマホの両方にTailscaleを入れて
同じアカウントで繋ぐだけで、まるで同じWi-Fiにいるかのようにアクセスできるようになります。

### 準備（最初の1回だけ）

1. **PC側**：https://tailscale.com/download からWindows版をダウンロード・インストールし、
   サインイン（Googleアカウント等で新規登録可）します。
2. **スマホ側**：App Store／Google Playで「Tailscale」を検索してインストールし、
   PCと**同じアカウント**でサインインします。
3. 両方とも「Connected（接続済み）」になっていることを確認します
   （PC側はタスクトレイのTailscaleアイコン、スマホ側はアプリ内で確認できます）。

これでPCとスマホは同じ「プライベートネットワーク（tailnet）」に参加した状態になります。
Trade Cockpitのサーバー自体は元々どのネットワークからでも受け付けられる設定
（`0.0.0.0`で待ち受け）になっているため、**サーバー側の追加設定は不要**です。

### 使い方

1. いつも通りPCで `start.bat` を起動します。
2. 黒いウィンドウに、同じWi-Fi用のURL（`http://192.168.x.x:8765/...`）に加えて、
   Tailscaleが接続済みなら
   ```
   --- 外出先（別Wi-Fi・4G/5G）から使う場合（Tailscale接続が必要） ---
   http://100.x.x.x:8765/trade-cockpit.html
   ```
   という行が追加で表示されます（`100.x.x.x`の部分はPCごとに違う、Tailscale専用のIPです）。
   この行が出ない場合は、PC側のTailscaleが「Connected」になっているか確認してください。
3. MagicDNS（Tailscale側の設定で有効になっている場合）が使える環境では、IPの代わりに
   `http://PC名:8765/trade-cockpit.html`（PC名はTailscaleの管理画面で確認できるデバイス名）
   でもアクセスできます。この行も接続済みなら黒いウィンドウに表示されます。
4. スマホ側でTailscaleアプリが「Connected」になっている状態で、手順2・3のURLを
   スマホのブラウザで開きます。別のWi-Fi、4G/5G回線のどちらでも同じように開けます。
5. ユーザー名・パスワードの入力（Basic認証）が設定されている場合は、Tailscale経由でも
   通常通り毎回入力が必要です（Tailscaleに繋がっていても認証は省略されません）。

**注意点**
- この方式は**PCが起動していて、`start.bat`のサーバーが動いていて、PC側のTailscaleも
  接続中**の3つがすべて揃っている間しか使えません。PCをスリープ・シャットダウンすると
  外出先からは繋がらなくなります。
- ルーターのポート開放やインターネットへの公開URLは一切使っていないため、
  Tailscaleのプライベートネットワークに参加していない第三者からはアクセスできません。

### つながらない時のチェックリスト

1. PC側のTailscaleが「Connected」になっているか
2. スマホ側のTailscaleが「Connected」になっているか
3. PCとスマホが同じTailscaleアカウント（同じtailnet）に入っているか
4. PC側で`start.bat`（Trade Cockpitサーバー）が起動中か
5. 黒いウィンドウに「外出先（別Wi-Fi・4G/5G）から使う場合」の行が表示されているか
   （出ていない＝サーバー起動時点でPC側Tailscaleが未接続だった可能性。表示後にTailscaleを
   繋いだ場合は`start.bat`を再起動すると表示されます）
6. Windows Defender ファイアウォールで python.exe の受信がブロックされていないか
   （設定 →「Windowsセキュリティ」→「ファイアウォールとネットワーク保護」→
   「アプリをファイアウォール経由で許可」で python.exe が有効になっているか確認）
7. ユーザー名・パスワード（Basic認証）を正しく入力しているか
8. 上記すべて問題なければ、スマホのTailscaleアプリから該当PCへの接続状態
   （アプリ内の「このデバイス」一覧でPCがオンライン表示か）を確認する

## 【重要】これまでのデータの引き継ぎ

これまで HTML を直接ダブルクリック（file://）で開いて銘柄を登録していた場合、
その保存データは今回のサーバー版（localhost）には自動では引き継がれません。
引き継ぎたいときは、次の移行を一度だけ行ってください。

1. これまで通り古い trade-cockpit.html をダブルクリックで開く
2. 右上「バックアップ↓」でJSONを保存
3. サーバー版（start.bat で開いた画面）で右上「復元↑」からそのJSONを読み込む

以降は、サーバー版のブラウザに自動保存されます。

## 取れるもの・注意

- 自動で取れる：ドル円・日経平均・ダウ・ナスダック・SOX・米10年債、
  および登録銘柄／マクロのニュース。数値は今日値と前日値の両方。
- 数値は遅延あり（前営業日終値〜数十分遅れ）で、リアルタイムの板ではありません。
  板・約定・発注は、将来の立花証券API連携の担当です。

---

## うまくいかない時

- 「サーバーに接続できません」と出る → start.bat の黒いウィンドウが閉じていないか確認。
  閉じていたら再度 start.bat を起動し、http://localhost:8765/trade-cockpit.html で使う。
- ブラウザが自動で開かない → 手動で http://localhost:8765/trade-cockpit.html を開く。
- 黒い画面が一瞬で消える / python が見つからない → Python の「Add to PATH」設定を確認。
- 数値やニュースが入らない → 黒いウィンドウのメッセージを確認。市場休場日はデータが出ないことがあります。
- ポートが使用中というエラー → 8765番が他で使用中かも。教えてください、番号を変えます。
