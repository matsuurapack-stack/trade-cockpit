# トレード・コックピット（サーバー版・Windows）

「リアルタイムデータを反映」ボタンを押すたびに、株価・指数・為替・ニュースを
その場で取ってくる仕組みです。裏で Python の小さなサーバーが動きます。

---

## 仕組み

`start.bat` を起動 → Python のサーバーが立ち上がり、ブラウザが自動で開く →
画面の「リアルタイムデータを反映」ボタンを押すと、その瞬間にデータを取得して反映します。

以前の run.bat / fetch_data.py / バックアップJSONの配置は、もう使いません。

---

## フォルダの中身（5つとも同じフォルダに）

- trade-cockpit.html … コックピット本体
- server.py … データを取ってくるサーバー（触らなくてOK）
- start.bat … 毎回これをダブルクリックして起動する
- setup.bat … 最初の1回だけの準備
- README.md … この手順書

---

## 初回だけの準備

Python はもう入っている前提です（まだなら python.org から「Add python.exe to PATH」に
チェックを入れてインストール）。

setup.bat をダブルクリックして、必要な部品（yfinance・feedparser）を入れてください。
※ すでに実行済みでも、もう一度やって問題ありません。

---

## 毎回の使い方

1. start.bat をダブルクリックします。
2. 黒いウィンドウが開き、ブラウザが自動でコックピットを開きます。
   （開かない場合は http://localhost:8765/trade-cockpit.html を開く）
3. 使っている間、黒いウィンドウは閉じないでください（サーバーが止まります）。
4. 日次モニター右上の「リアルタイムデータを反映」ボタンを押すと、
   ドル円・日経平均・ダウ・ナスダック・SOX・米10年債 が
   今日値／前日値ともに入り、登録銘柄とマクロのニュースも入ります。
   何度押しても、そのたびに最新を取り直します。
5. 終わるときは、黒いウィンドウを閉じてください。

---

## スマホから使う

start.bat を動かしているPCと**同じWi-Fi**につないだスマホ・タブレットからも見られます。

1. PCで start.bat を起動すると、黒いウィンドウに
   `http://192.168.x.x:8765/trade-cockpit.html` のような行が表示されます（数字はPCごとに違います）。
2. 初回だけ、Windowsで「Windows セキュリティの重要な警告」（ファイアウォールの確認）が出ることがあります。
   「プライベートネットワーク」にチェックが入っていることを確認して「アクセスを許可する」を押してください。
   （この確認が出ないとスマホから繋がりません）
3. スマホのブラウザで、手順1のURLをそのまま開きます。

**注意点**
- PCの黒いウィンドウを閉じるとスマホからも使えなくなります（PCがサーバー役のため）。
- 同じWi-Fiにいる人なら誰でもこのURLで見られます（パスワード等の制限は付けていません）。
  カフェ等の公衆Wi-Fiでは使わないでください。
- 登録銘柄やメモなどのデータは**端末（ブラウザ）ごとに別々に保存**されます。PCで登録した銘柄が
  スマホに自動で出てくるわけではありません。同じ内容にしたい場合は、PC側で「バックアップ↓」→
  スマホ側で「復元↑」からJSONを読み込んでください。

---

## 【重要】これまでのデータの引き継ぎ

これまで HTML を直接ダブルクリック（file://）で開いて銘柄を登録していた場合、
その保存データは今回のサーバー版（localhost）には自動では引き継がれません。
引き継ぎたいときは、次の移行を一度だけ行ってください。

1. これまで通り古い trade-cockpit.html をダブルクリックで開く
2. 右上「バックアップ↓」でJSONを保存
3. サーバー版（start.bat で開いた画面）で右上「復元↑」からそのJSONを読み込む

以降は、サーバー版のブラウザに自動保存されます。

---

## 取れるもの・注意

- 自動で取れる：ドル円・日経平均・ダウ・ナスダック・SOX・米10年債、
  および登録銘柄／マクロのニュース。数値は今日値と前日値の両方。
- 数値は遅延あり（前営業日終値〜数十分遅れ）で、リアルタイムの板ではありません。
  板・約定・発注は、将来の立花証券API連携の担当です。

---

## うまくいかない時

- 「サーバーに接続できません」と出る → start.bat の黒いウィンドウが閉じていないか確認。
  閉じていたら再度 start.bat を起動し、http://localhost:8765/trade-cockpit.html で使う。
- ブラウザが自動で開かない → 手動で http://localhost:8765/trade-cockpit.html を開く。
- 黒い画面が一瞬で消える / python が見つからない → Python の「Add to PATH」設定を確認。
- 数値やニュースが入らない → 黒いウィンドウのメッセージを確認。市場休場日はデータが出ないことがあります。
- ポートが使用中というエラー → 8765番が他で使用中かも。教えてください、番号を変えます。
